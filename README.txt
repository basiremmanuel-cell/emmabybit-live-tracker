EMMABYBIT — LIVE BYBIT SPOT TRACKER

CONTENTS
- index.html: complete mobile-friendly dashboard.

FEATURES
- Reads public Bybit Spot market ticker data; no API key, account login, wallet, or private key.
- Screens USDT pairs matching the built-in meme-coin keyword list.
- Ranks candidates and displays BUY WATCH / WATCH / SELL WATCH / HOLD labels, price, 24h change, turnover, signal reason and illustrative risk levels.
- Refreshes every 10 seconds; manual refresh and pause/resume controls.
- Works as a static GitHub Pages site.

INSTALL / PUBLISH ON GITHUB PAGES
1. Download and extract Emmabybit.zip.
2. Open your GitHub repository (the one used for your Bybit tracker).
3. Upload index.html to the repository's publishing root (same level as README.md), then commit.
4. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the Pages deployment to finish and open the published URL.

TROUBLESHOOTING
- The published page must contain this non-empty index.html file in the selected Pages root.
- If the page is blank, check that the repository's index.html was committed and that Pages is publishing the same branch/folder.
- If the page opens but shows a Bybit connection issue, try again on a normal internet connection. Bybit API access can vary by network/region/browser.
- This is a static website. It does not execute trades or connect to a Bybit account.

RISK
Signals are heuristic market screens, not financial advice or guaranteed buy/sell calls. Meme assets are highly volatile. The stop/target figures are illustrative only.
